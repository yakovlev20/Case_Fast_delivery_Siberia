# Case_Fast_delivery_Siberia

Веб-приложение для распределения неделимых заказов по машинам с проверкой вместимости.
Учебный проект: система назначает заказы на машины, показывает долю назначенного веса
и позволяет выгрузить нераспределённые заказы в CSV.

## Исходные условия 
Заказчик — ООО «Быстрая Доставка Сибирь», региональный оператор доставки для интернет-магазинов и розничных сетей. Автопарк — 45 машин, три склада, более 300 точек доставки в день. Логисты вручную строят маршруты в Excel и картах, каждый по своей привычной схеме.
Не учитываются в едином плане пробки, временные окна, приоритеты клиентов и загрузка машин. Машины ездят полупустыми; случаются опоздания и повторные выезды. Растут пробег и расход топлива, клиенты жалуются. Руководству не хватает общей картины эффективности.
## Цели заказчика
Сократить суммарный пробег на 12–18%; довести долю доставок в срок до 95% и выше; повысить загрузку машин; уменьшить ручной труд. Нужны понятные показатели для логистов и руководства.
